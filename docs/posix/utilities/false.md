#### <span id="tag_20_43_01"></span>NAME

> false — return false value

#### <span id="tag_20_43_02"></span>SYNOPSIS

> `false`

#### <span id="tag_20_43_03"></span>DESCRIPTION

> The *false* utility shall return with a non-zero exit code.

#### <span id="tag_20_43_04"></span>OPTIONS

> None.

#### <span id="tag_20_43_05"></span>OPERANDS

> None.

#### <span id="tag_20_43_06"></span>STDIN

> Not used.

#### <span id="tag_20_43_07"></span>INPUT FILES

> None.

#### <span id="tag_20_43_08"></span>ENVIRONMENT VARIABLES

> None.

#### <span id="tag_20_43_09"></span>ASYNCHRONOUS EVENTS

> Default.

#### <span id="tag_20_43_10"></span>STDOUT

> Not used.

#### <span id="tag_20_43_11"></span>STDERR

> Not used.

#### <span id="tag_20_43_12"></span>OUTPUT FILES

> None.

#### <span id="tag_20_43_13"></span>EXTENDED DESCRIPTION

> None.

#### <span id="tag_20_43_14"></span>EXIT STATUS

> The *false* utility shall always exit with a value between 1 and 125, inclusive.

#### <span id="tag_20_43_15"></span>CONSEQUENCES OF ERRORS

> Default.
