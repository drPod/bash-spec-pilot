## <span id="tag_20"></span>3. Utilities

This chapter contains the definitions of the utilities, as follows:

- Mandatory utilities that are present on every conformant system

- Optional utilities that are present only on systems supporting the associated option; see [*1.8.1 Codes*](../basedefs/V1_chap01.html#tag_01_08_01) for information on the options in this volume of POSIX.1-2024
