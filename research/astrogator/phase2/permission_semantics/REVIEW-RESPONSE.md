# Response to independent Opus review, round 2

The review was a model review, not human approval. Predictions were checked against source or executed before adoption.

1. **`copy.directory_mode` bypass — fixed.** The opt-in guard now normalizes or declines this argument as well as the six built-ins' `mode` arguments. `directory_mode` always targets directories, so complete symbolic `X` is constant there. Five new verifier cases cover partial, dynamic, complete-directory-X, and quoted-octal values. The former implementation and complete results are retained in `archive/guard-v1/`.
2. **Duplicate raw YAML keys — already rejected upstream; executed confirmation added.** `mod_result.add_arg` in upstream `lib/ansible/parser.ml` records a duplicate-argument error before the semantic guard runs. Raw duplicate state/recurse/mode inputs were sent without PyYAML normalization to both flag modes; all six runs fail with the duplicate diagnostic. No new first-binding/last-binding premise is assumed.
3. **Differential scope — narrowed explicitly.** The 557,056 comparisons exercise Ansible's three symbolic helper functions. They do not cover the full `set_mode_if_different`, numeric/octal application path, symlink/lchmod, or parent-directory creation. Accepted octal parsing and the class-mask argument have separate source/normalizer evidence. The normalizer binary is byte-identical before and after the argument-guard change.
4. **a32 “unverifiable” — review claim corrected by execution.** No supported constant explicit mode assignment matches its symbolic-X query, and the correct X implementation is declined. But removing the `mode` argument yields acceptance with an initial-mode residual in both flag modes. That variant fails both concrete fixture states, which do not satisfy the residual. Therefore “a32 cannot be verified under the flag” is too strong; the docs now distinguish unsupported explicit updates from conditional acceptance of an unchanged state.
5. **7000/0000 interpretation — disclosed, not asserted as intended language semantics.** All three special bits already emitted `u=s,g=s,o=t` upstream; normalizing that complete assignment gives exact7000. An empty ordinary-permission AST maps to0000 under the proposed interpretation. These remain design choices for Aaron. The surface spelling `read=none` is not supported by the current semantic analyzer, so it is not used as evidence of a public-language behavior.
6. **Coverage cost — stated directly.** The supplied-corpus run recovers zero accepts and loses decisions. The normalizer's compatibility benefit appears in authored panels only. The corpus was rerun after the directory-mode fix; summaries distinguish unavailable from rejected and preserve available local labels. No accuracy improvement is claimed.
7. **Other model mode sources — explicitly outside scope.** `mode_of_umask`, inherited/user-home modes, and initial-state residual assumptions remain. The opt-in boundary is not a claim that every modeled mode is a concrete constant or that Astrogator is globally sound. Every compared result identifies default versus `--constant-modes` through its variant or frozen run configuration.

The v2 replay initially exhausted the shared job slice's Docker-client thread budget. Failed attempts remain in `archive/thread-limit-attempt/`; the completed replay used one sequential bounded Docker container with client `GOMAXPROCS=2`, without changing host limits. Infrastructure failures are not correctness labels.
